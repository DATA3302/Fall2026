# Network reference figures

Source: `Fall2026/tmp/477-Slides/17-Networks.pdf` (Cal Poly CSC 477, “Network Visualization”). Filenames retain the original PDF page number, not an added companion-slide number.

- `native/page-*-image-*.png`: original embedded raster objects, at their native pixel dimensions. PDF soft masks are restored as PNG alpha where present; these are not screenshot crops or upscaled images.
- `native/page-*-native.svg`: PDF-native paths, embedded raster objects, and outlined text, clipped/reframed to the figure rather than rasterized. Surrounding slide headings/explanatory text are removed where necessary. SVG IDs are page-namespaced to avoid collisions when the deck runtime inlines multiple figures.
- Page 12 retains the numbered source DAG rather than inventing a replacement graph.
- Pages 14–15 preserve the source food-web diagrams, edge directions, legend, and progression. No answer/data have been inferred from the pictures.
- Pages 20–21 retain the original PivotGraph drawings, including aggregate edge widths.
- Pages 27–28 intentionally repeat the source's Shape of Song composition. Page 28 adds an opt-in external view of the same referenced project.
- Pages 34–35 preserve the original matrix comparison and overlay, including source ordering.
- Page 42 preserves the visible PDF arrangement of the two indentation examples; it does not pretend the clipped source file listing is complete.

- Page 55 separates the two embedded originals: the Prague schematic and the NYC subway network, rather than repeating one slide screenshot.
